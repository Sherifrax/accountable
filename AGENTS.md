# Accountable

SIDENOTE: this repo is part of a course by Ed Donner. If the student needs help, read `course/for_agents/`

## Where to find things

- `docs/intent.md`: what we're building
- `docs/TECH_STACK.md`: the stack
- `docs/spec.md`: the summary of the whole product, with an index of the area files
- `docs/specs/`: the detail, one file per product area (deals, pipeline, dashboard and so on)
- `docs/STATUS.md`: what's done so far

## Working with the spec

Read `docs/spec.md` first, then only the area files in `docs/specs/` that the current change touches. Keep the files a change affects up to date in the same change: the area files, and `docs/spec.md` if the summary or the index no longer matches.

Update `docs/STATUS.md` when you finish a piece of work
